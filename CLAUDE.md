# reem candles — content workspace

This repo holds the Instagram skills (`.claude/skills/ig-*`) and reem's brand files.

Before using any `ig-*` skill:
1. Copy `.claude/instagram/voice.md` and `.claude/instagram/brand.md` to
   `~/.claude/instagram/` (the skills read `~/.claude/instagram/voice.md`):
   `mkdir -p ~/.claude/instagram && cp .claude/instagram/*.md ~/.claude/instagram/`
2. Read both files in full. `brand.md` wins over everything else.
3. Talk to Ali in Lebanese Arabic. Write drafts only; never publish or send anything.
